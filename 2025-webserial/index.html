ℹ️ How to Use

  1. Upload the Arduino sketch to your board (see arduino_sketch.ino)
  2. Click "Connect to Arduino" and select your Arduino port
  3. Send commands or use the quick buttons
  4. Watch the serial monitor for responses from Arduino

Note: Web Serial API requires HTTPS or localhost. Works in Chrome, Edge, and Opera.
